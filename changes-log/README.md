# Changes log

One file per working session, newest first. These record **why** a change was
made and what was traded away — the reasoning that a diff and a commit message
do not carry.

Written and updated by the `changes-log` skill
(`.claude/skills/changes-log/SKILL.md`).

| Date | Entry | Covers |
|---|---|---|
| 2026-08-20 | [Dashboard & Meditate UI pass, iOS simulator CI](2026-08-20-dashboard-meditation-ui.md) | Shortcut block scaling, carousel height, album grid cell extent, `AlbumCard` + `TagPill` extraction, `UI_PREVIEW` build, Codemagic iOS |

## Conventions

- Filename: `YYYY-MM-DD-short-slug.md`
- One file per day. A second session on the same day appends to the existing
  file under a new `##` heading rather than creating a second file.
- Add a row to the table above whenever a file is created.
